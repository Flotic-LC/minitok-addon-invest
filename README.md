# minitok-addon-invest

Toss Securities Open API add-on adapter for minitok.

## Running

`ash
node runner.js          # Start trading engine
node admin-server-full.js  # Start admin bot
npm test                # Run tests
node backtest.js        # Backtest
`

## API Endpoints (port 9100)

/health, /metrics, /knowledge, /meta-cognition, /self-healing,
/confidence, /lifecycle, /cross-market, /var, /risk, /backtest, /dashboard, /admin/*
